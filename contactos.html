Sobre este website

Este website foi criado como trabalho escolar sobre o tema Animais. Cumpre os seguintes requisitos técnicos:

  • Imagens guardadas na pasta Imagens/
  • Imagens retiradas de bancos públicos gratuitos (Unsplash – listado em Lusodados)
  • Direitos de autor e de imagem respeitados
  • Links para ficheiros, zonas da página (#âncoras) e sites externos
  • Caminhos relativos
  • CSS em ficheiro separado (css/styles.css)
  • Fontes de utilização livre (Google Fonts)
  • Bootstrap 5
  • Tabelas e divs (grid Bootstrap) para alinhamento
  • Menu de navegação responsivo
  • Boas práticas de programação (HTML semântico, acessibilidade básica, código limpo)

Fontes de imagens

Todas as fotografias foram descarregadas de Unsplash (licença gratuita para uso pessoal e comercial).

Como colocar o website online

  1. Cria uma conta no GitHub
  2. Cria um repositório novo e faz upload de todos os ficheiros
  3. Vai a Settings → Pages e ativa o GitHub Pages (branch main)
  4. O site ficará disponível em: https://teu-utilizador.github.io/nome-do-repositorio/

Alternativas grátis: Netlify ou Vercel (basta arrastar a pasta do projeto).
